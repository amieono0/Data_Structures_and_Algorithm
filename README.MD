Mathematical Expression Evaluator

Description

This project uses Python and a Stack data structure to evaluate mathematical expressions. It reads expressions from input.txt, calculates the answers, and saves the results in output.txt.

Project Files

* main.py – Contains the program code.
* input.txt – Contains the expressions to evaluate.
* output.txt – Contains the calculated results.

How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run py main.py.
4. Open output.txt to see the results.

Technologies

* Python 3.14.8
* Visual Studio Code
* Stack data structure
